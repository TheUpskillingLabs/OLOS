\section{What we are building}
Three nested identities, each stated in our own docs. \textbf{Near term:} ``the build-cycle operating system'' --- field observations $\rightarrow$ problem statements $\rightarrow$ votes $\rightarrow$ pods $\rightarrow$ projects $\rightarrow$ weekly Learning Logs $\rightarrow$ showcase, replacing forms and spreadsheets \ev{README}. \textbf{Mid term:} ``The Labs runs like open source'' --- Sectors as durable problem-domain communities, Cycles as incubator cohorts, Local Labs as the place-based tenancy spine, the org running its own machinery via org cycles/workstreams \ev{SECTOR\_MODEL, LOCAL\_LABS, ORG\_CYCLES}. \textbf{Long term: Project Ortelius} --- ``the legitimate, participatory, consented, open civic counterpart to Foundry'': a provenance-complete, consent-governed corpus of community sensemaking, with declared lead buyers of a frontier AI lab plus civic leaders (owner decision 2026-07-05) \ev{ORTELIUS\_NORTHSTAR}. Intended outcome, layered: members shipping civic projects in teams $\rightarrow$ a compounding sector commons $\rightarrow$ a clean, consented sensemaking corpus.

\section{Where the system stands}
Everything is \textbf{live in production alpha with real participant data}; \texttt{dev} and \texttt{main} are fully merged (promotion is near-daily). The chain is at \textbf{100 migrations}; roughly two-thirds of it and 74 of 118 API routes postdate mid-June. \textbf{Built:} the full cycle engine (verified end-to-end), Learning/Leadership Logs (replaced Pulse in July), the social layer, labs/sectors/org-cycle structure, public CMS with two-way Luma event sync, owner console, view-as debugging lens, member task system. \textbf{One slice deep:} sensemaking --- field-survey intake, results, and citable per-observation anchors exist; the entire Ortelius graph spine (extracts, swipes, canvas, embeddings, \path{asset_links}) has \textbf{zero migrations}. The Frame-Creation canvas (``Triangulator'') lives in a second repo (\path{TheUpskillingLabs/triangles}); the current cohort does sensemaking \emph{there}, in per-team GitHub working folders that deep-link back to OLOS survey rows (PR \gh{302}). An in-app port plan exists but has sat unmerged since 07-06 (PR \gh{185}). Which path wins is our biggest open architecture fork.

\section{How the team operates}
Development is agent-driven: roughly half of all commits are Claude-authored, steered through Claude Code sessions and the GitHub App; five agent roles are checked into \path{.claude/agents/}; the product itself deliberately runs almost no AI (one Haiku call for pod/project names; everything else is copy-prompt/BYO-LLM behind the Ortelius consent gate). Process reality: \textbf{zero formal reviews exist across all $\sim$360 PRs}, $\sim$97--100\% self-merge, no branch protection, and CODEOWNERS still routes every review request to me (absent since June). Since 07-30 the stream collapsed to a \textbf{single operator} --- every PR from \gh{318} to \gh{359} was authored \emph{and} merged by MJ, with HQ assisting on branches; Brendan's last merges are 07-25, amguzzi's 07-27. \textbf{All activity stops 2026-08-04} with the tree clean. I do not know from the repo whether this is a planned pause or reallocation.
